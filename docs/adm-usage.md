> 适用版本：2026-10-19 之后（`roles.js` + `workshop.js` 已上线）。
> 角色：**adm（管理员）**。低于 owner（222222222），高于 guest。

## 0. 一句话：怎么用

**在 QQ 里私聊 Molly，用「命令 」开头说话。** 群里永远不执行命令，这是硬边界。

```
命令 帮我把今天群里的消息统计一下
命令 写一个插件，功能是每天 9 点报天气，先只有草稿不用装
```

前缀三选一：`命令 `（空格）、`命令：`、`命令:`（半角冒号）。

---

## 1. 为什么必须带「命令 」

Molly 默认只会聊天。她**不会**把自然语言当成任务去执行 —— 这是故意关掉的：曾经放开过，结果「我今天好累」也被当成任务开干。

所以：
- 想聊天 → 直接说话，不用前缀
- 想让她干活 → `命令 ` + 你要她做的事

## 2. 你现在能做什么

| 能力 | 怎么说 | 说明 |
|---|---|---|
| 让她干活 | `命令 <任务>` | 她会起一个干活会话，用 DSH 的agent能力执行；过程会播报、结束把结果发回你的私聊 |
| 写插件草稿 | `命令 写个插件：<需求>` | 落到 `${MOLLY_ROOT}\plugin-workshop\<slug>\`，**不会装进线上** |
| 让她测插件 | `命令 测一下工坊里的 xxx` | 两级：`node --check` + 子进程 stub ctx 跑 apply，20 秒超时 |
| 打包 | `命令 把 xxx 打包` | 产出 `dist\<slug>-<版本>-<时间>.zip` + `.sha256`，状态改 `packaged` |
| 看清单 | `命令 列一下工坊里有什么` | 每个插件一行：slug · 版本 · 状态 · 最近测试 |
| 审批 | 直接回 `1` / `0` | 加好友、被拉群时会同时发给你和主人，谁先回谁生效 |
| 普通聊天 | 直接说 | 你和主人在 `allowedUsers` 里，正常对话 |

工坊根目录：`${MOLLY_ROOT}\plugin-workshop\`
- `<slug>\manifest.json` —— 元信息（名字/版本/状态/最近测试结果）
- `<slug>\index.js` —— 插件本体（默认导出 cordis 插件）
- `<slug>\README.md`
- `dist\*.zip` —— 打包产物，带 sha256

## 4. 三个可以直接抄的例子

**让她写一个插件**

```
命令 写个插件叫 daily-weather，功能是每天早九点把这个群昨天的消息数统计出来，
先只出草稿和 README，不用装，写完你自己测一遍再告诉我结果
```

**让她测**

```
命令 测一下工坊里的 daily-weather，把 node --check 和 apply 的结果贴给我
```

**让她打包**

```
命令 把 daily-weather 打包成 zip，告诉我 sha256
```

## 5. 几个坑（提前告诉你，省得来回问）

1. **`/工坊 新建` 这类斜杠命令目前不存在**。工坊没有注册聊天斜杠命令，只能自然语言（见上面「命令 写个插件…」）。想要斜杠命令得另开一轮开发。
2. **同一个任务别催多次**。她一个任务在跑的时候再发一条，可能被当成新任务。她播报里会写「开工」「做完了」。
3. **群里说命令没用**，只私聊生效。
4. **插件写完不会自动可用**。打包只是 zip，装到线上永远需要主人重启/重载，她没有这个权限。
5. 你写好的插件如果想上线，把 zip 路径发给主人，由主人决定要不要装。

## 7. 已知未验证项（主人知道即可）

`molly_workshop` 是否真的在干活会话里可调用，目前**只在模块层验证过**（`Workshop.list()` / `.test()` 直接调用正常），没有做过「以他的身份发一条命令 → 看 agent 是否真调到工具」的端到端实测。

最快的验证：让他私聊发一条 `命令 列一下工坊里有什么`，如果回的是插件清单（含 `demo-hello packaged v0.1.0`），就是通的。
