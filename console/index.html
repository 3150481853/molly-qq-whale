重新登录 QQ（扫码）

当前后端：读取中…。点按钮只会重启 QQ 客户端，不会重启 Molly 插件、网关和控制台。

  • SnowLuma 后端：触发计划任务 SnowLuma-Relogin，约 10~25 秒后 QQ 窗口弹出，用手机扫码即可（SnowLuma 进程不动，设备指纹不变）。
  • 回滚后端：现场生成一张登录二维码（约 2–6 秒），用手机 QQ 扫码，扫完即失效。
  • 扫码后 QQ 窗口会自动关闭；看到「Molly 已连接 QQ」就成功了，不用再刷新。
  • 30 秒还不见窗口：先看 ${MOLLY_ROOT}\qq-whale\out\snowluma-runtime.out.log 和 ${MOLLY_ROOT}\qq-whale\out\snowluma-boot.log；也可以在「运维」页的日志里选「SnowLuma 运行 / 启动」看最近 200 行。
  • 还不行就去「守护」看 watchdog 结论，或到「执行块」重新检查连接。

点「重新登录 QQ（扫码）」：SnowLuma 后端会触发计划任务重启 QQ 客户端，约 10~25 秒后 QQ 窗口弹出，用手机扫码。

不会重启 Molly 插件、网关和控制台。回滚后端则改为现场生成二维码（约 2–6 秒，2 分钟过期，最多自动换 3 张）。

本机存档

—

提交之后会怎样

  1. 本机先留一份存档在 <Molly>\qq-whale\out\feedback，断网、论坛挂了都不会丢。
  2. 能发就发：论坛放权后会直接发到帖子里；没放权就把写好的 Markdown 放到下面，一键复制粘过去。
  3. 提醒站长：提交成功会同时给站长推一条消息（配置了推送通道才发）。
  4. 从 GitHub 部署的：帖子发不出去时，结果里会多一个「去 GitHub 提 issue」，标题和正文都替你填好。

日志会自动脱敏：QQ 号打码、本机路径换成 <本机>、token 一类字段直接隐去。
